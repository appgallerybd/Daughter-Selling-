# বিয়ে হিসাব — টাকা ওঠানো ও খরচের খাতা

বিয়ে বাড়ির টাকা ওঠানো, খরচ এবং বাকি আদায়ের সম্পূর্ণ হিসাব — বাংলা ভাষায়, চার্ট ও ইনফোগ্রাফিক্স সহ।

## ফিচার

- **ড্যাশবোর্ড** — মোট আদায়, প্রতিশ্রুতি, বাকি, খরচ ও হাতে থাকা টাকার সারসংক্ষেপ; লক্ষ্য পূরণের রিং; দিনভিত্তিক আদায় ও ক্রমপুঞ্জিত চার্ট; পক্ষ, সম্পর্ক ও খাতভিত্তিক বিভাজন; শীর্ষ অনুদানকারী ও সাম্প্রতিক লেনদেন।
- **টাকা ওঠা** — অনুদানকারীর নাম, ফোন, পক্ষ (বর/কনে), সম্পর্ক, মাধ্যম (নগদ, বিকাশ, নগদ, রকেট, ব্যাংক, চেক), প্রতিশ্রুতি ও প্রাপ্তি আলাদা করে লেখা যায়। নাম/ফোন সার্চ, পক্ষ–সম্পর্ক–মাধ্যম–অবস্থা ফিল্টার, সাজানো এবং সম্পাদনা/মুছে ফেলা।
- **খরচের হিসাব** — খাতভিত্তিক খরচ (খাবার, হল, সাজসজ্জা, পোশাক, গহনা, ফটোগ্রাফি, সংগীত, যাতায়াত, অন্যান্য), বাজেট ব্যবহারের অগ্রগতি।
- **রিপোর্ট** — প্রিন্ট/PDF উপযোগী হিসাব বিবরণী, বাকি আদায়ের তালিকা, স্বাক্ষরের ঘর; CSV ডাউনলোড।
- **সেটিংস** — বিয়ের তথ্য ও লক্ষ্য, JSON ব্যাকআপ ডাউনলোড/রিস্টোর, **ডিভাইস থেকে ডিভাইসে শেয়ার**, নমুনা হিসাব, সব ডেটা মুছে ফেলা।
- মোবাইল ও ডেস্কটপ — দুই জায়গায় রেসপন্সিভ, সম্পূর্ণ বাংলা ইন্টারফেস, বাংলা সংখ্যা ও তারিখ।

## এক ডিভাইস থেকে আরেক ডিভাইসে শেয়ার

সেটিংস → **ডিভাইস থেকে ডিভাইসে শেয়ার** → “শেয়ার কোড তৈরি করুন”। তারপর:

1. **শেয়ার লিংক** কপি করে WhatsApp/Messenger-এ পাঠান — অন্য ফোনে লিংকটি খুললেই “শেয়ার করা হিসাব পাওয়া গেছে”
   জানালা আসবে। **সব প্রতিস্থাপন** (পুরো হিসাব নেওয়া) বা **একসাথে যোগ করুন** (দুই ফোনের এন্ট্রি জোড়া
   লাগানো, একই এন্ট্রি দুইবার হবে না) বেছে নিন।
2. শুধু **কোড** পাঠাতে চাইলে “কোড কপি” করে পাঠান; অন্য ডিভাইসে সেটিংসের ২ নম্বর ঘরে পেস্ট করে
   **কোড যাচাই করে নিন** চাপুন।

কোডের ভেতরেই সম্পূর্ণ হিসাব সংকুচিত (deflate) হয়ে থাকে — কোনো সার্ভার, ডেটাবেস বা লগইন লাগে না,
তাই Vercel/Netlify-এর ফ্রি স্ট্যাটিক হোস্টিং-এও কাজ করে। এর মানে কোডটি ছোট নয় (৩০–৪০০ এন্ট্রিতে
কয়েক কিলোবাইট) এবং লিংক/কোড যার হাতে যাবে সে-ই হিসাবটি পড়তে পারবে — শুধু বিশ্বস্ত মানুষকে দিন।

## চালানো

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # প্রোডাকশন বিল্ড
npm run typecheck
```

## Vercel-এ ডিপ্লয়

1. এই রিপোজিটরি GitHub-এ পুশ করা আছে; [vercel.com/new](https://vercel.com/new) → **Import Git Repository**
   → `appgallerybd/Daughter-Selling-` বেছে নিন।
2. Framework Preset: **Vite** (স্বয়ংক্রিয়ভাবে ধরা পড়ে), Build Command `npm run build`, Output Directory `dist`।
   `vercel.json`-এ এগুলো আগেই দেওয়া আছে — কিছু বদলাতে হবে না।
3. **Deploy** চাপুন। এরপর পাওয়া লিংকটাই অ্যাপের ঠিকানা; শেয়ার কোড/লিংকও ওই ঠিকানা থেকেই তৈরি হবে।

> ডেটা প্রতিটি ব্রাউজারে আলাদা থাকে (localStorage)। শেয়ার কোড নতুন ডিভাইসে হিসাবটা কপি করে —
> একসাথে দুই ডিভাইসে লাইভ সিঙ্ক করে না। লাইভ সিঙ্ক চাইলে লগইন ও একটি ডেটাবেস যোগ করতে হবে।

## ডেটা

সব হিসাব ব্রাউজারের `localStorage`-এ (`biye-hisab:v1`) সংরক্ষিত থাকে — কোনো সার্ভারে পাঠানো হয় না।
প্রথমবার খুললে নমুনা হিসাব দেখা যায়, সেটিংস থেকে মুছে নিজের ডেটা লেখা যায়। ডিভাইস বদলাতে হলে
সেটিংস → **ব্যাকআপ ডাউনলোড** করে নতুন ডিভাইসে **ব্যাকআপ থেকে ফেরান**, অথবা **ডিভাইস থেকে ডিভাইসে
শেয়ার** কোড/লিংক ব্যবহার করুন।
